# Change: 优化 CSS 样式复用，减少主包体积

## Why

项目中页面和组件存在大量重复的 CSS 声明，这些重复样式增加了小程序主包体积。`common.scss` 已经提供了丰富的全局工具类（如 `.flex`, `.m-*`, `.p-*`, `.fs-*`, `.text-center` 等），但页面和组件中仍在使用内联样式或重复声明相同的 CSS 规则。通过优先复用全局样式，将重复的 CSS 声明替换为 class 组合，可以显著减少主包体积，提升小程序加载性能。

## What Changes

- **优先复用全局样式**：将页面和组件中重复的 CSS 声明替换为 `common.scss` 中已有的工具类组合
- **保留必要的局部样式**：对于 `common.scss` 中没有的样式或不符合全局样式的特殊样式，在页面/组件文件中保留声明
- **统一样式规范**：建立样式复用优先原则，避免未来再次出现重复声明
- **减少主包体积**：通过移除重复的 CSS 代码，降低小程序主包大小

## Impact

- **受影响的范围**：
  - 所有页面文件（`src/pages/**/*.vue`）
  - 所有组件文件（`src/components/**/*.vue`）
  - 其他业务模块的 Vue 组件（`src/**/*.vue`）
  
- **受影响的代码**：
  - 所有包含 `<style lang="scss" scoped>` 的 Vue 文件
  - 需要检查并替换重复的 CSS 声明为全局工具类

- **性能影响**：
  - 主包体积减少（预期减少 10-30% 的 CSS 代码）
  - 小程序加载速度提升
  - 样式维护成本降低

- **风险**：
  - 需要全面测试确保样式表现一致
  - 某些特殊样式可能需要补充到全局样式中
